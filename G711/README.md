# G711 Autopilot Panel – MobiFlight configurations

| File | Sim | Coverage |
| --- | --- | --- |
| `PW-G711.mfmc` | – | Board configuration for the panel |
| `G711-MSFS-M600.mfproj` | MSFS 2024 | Tailored for the FSReborn Expert Series 02: Piper M600. All buttons, knobs and lights mapped to the aircraft's own events. |
| `G711-MSFS-Generic.mfproj` | MSFS | Best effort for other aircraft and autopilots, using standard sim events. Some functions may not work in every aircraft. |
| `G711-XPL-generic.mfproj` | X-Plane | Best effort for other aircraft and autopilots, using standard X-Plane commands. Some functions may not work in every aircraft. |

The generic configurations do not assign the XFR button, and the X-Plane configuration does not assign the FMS/MAN speed selector, because there is no standard equivalent.
